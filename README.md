THE WORLD IN ONE DAY — a front page summing up 22 November 2026's world news in one 1024×1024 image: 36 stories across 7 regions, 6 big numbers, 3 big illustrated headlines, a map with 12 pins and 23 numbered briefs, plus a DATE CHECK box for what was left out. Drawn by hand with code (Pillow), no photos, no wire images. Every story was first reported on 22 November 2026.

## Run it

```sh
python3 main.py
```

Writes `entry.png` (1024×1024, PNG) to `$MAKEFUN_OUTPUT_DIR` (default `/output`). Runs twice byte-identical, no network.
